# Referencia de Mods - Servidor Project Zomboid

Lista completa de 32 mods implementados en el servidor, con descripción breve y enlace a Steam Workshop.

---

## Frameworks

1. **damnlib** (Workshop: 3171167894)
   Framework central para todos los mods de KI5 (vehículos, trailers). Obligatorio si se usan mods KI5.
   https://steamcommunity.com/sharedfiles/filedetails/?id=3171167894

2. **StarlitLibrary** (Workshop: 3378285185)
   Framework de dependencias para otros mods (Burd's Survival Journals, etc.).
   https://steamcommunity.com/sharedfiles/filedetails/?id=3378285185

3. **MoodleFramework** (Workshop: 3396446795)
   API para crear moodles personalizados. OBSOLETE - removido de Steam, verificar compatibilidad.
   https://steamcommunity.com/sharedfiles/filedetails/?id=3396446795

4. **NeatUI_Framework** (Workshop: 3508537032)
   Framework UI compartido para mods de interfaz como CleanUI.
   https://steamcommunity.com/sharedfiles/filedetails/?id=3508537032

5. **TchernoLib** (Workshop: 3389605231)
   API con herramientas variadas para modders. Dependencia de varios mods.
   https://steamcommunity.com/sharedfiles/filedetails/?id=3389605231
